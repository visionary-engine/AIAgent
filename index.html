課題の本質

AI導入の成果格差は、
「設計できる人材」の有無で決まる。

生成AIツールの導入は進んでいます。しかし成果に直結している企業はわずか13%。 差は、ツールの選択や予算規模ではありません。

高い成果を上げている企業ほど、AIを単なる効率化ツールではなく 業務プロセスや事業構造の変革手段として捉え、 業務への本格的な組み込みとガバナンス整備を並行して進めています。

転換点

AIは今、「個人のツール」から
「組織のインフラ」へ移行しています。

この転換期に求められるのは、プロンプトを書ける人ではなく、
AIエージェントを業務・組織に組み込む設計ができる人です。

これまで

AIは"個人の武器"だった

  • プロンプトを工夫して個人の生産性を上げる
  • 成果は担当者のスキルに依存する属人的な活用
  • ツールが乱立し、組織として管理できない
  • 「使える人」と「使えない人」の格差が広がる
NOW
これから

AIは"組織の業務基盤"になる

  • 業務プロセスにAIエージェントを組み込む設計
  • ROIを定義し、組織全体の生産性を可視化する
  • ガバナンス体制を整え、持続可能な運用を実現
  • 「設計できる人材」が組織変革を牽引する
3つの障壁

なぜ、AIは組織に定着しないのか。

多くの企業に共通する「AI実装の壁」があります。
これらは、ツールの問題ではなく、人材と設計の問題です。

BARRIER 01

戦略設計と実装の分断

「何のためにAIを入れるか」が曖昧なまま、ツール導入が先行します。 ROI設計や業務分解が不十分なまま進むプロジェクトは、 成果を出せずにPoC止まりになります。

BARRIER 02

評価基準の不在

AI人材を「採用・育成・評価」するための共通指標がありません。 「プロンプトが上手い人」への属人的な依存が続く限り、 組織的なAI活用は実現できません。

BARRIER 03

野良AIの乱立とガバナンス不全

個人が独自に作ったAIエージェントが組織内で増殖し、 品質・セキュリティ・管理責任がブラックボックス化します。 全社的なAI活用を阻む最大のリスクです。

資格制度

「設計」と「実装」を分離した、
国内初のAIエージェント人材基準。

本資格は、企業内で役割が異なる「戦略設計」と「技術実装」を明確に分離した2階層構造です。 現在募集中のAIエージェント・ストラテジストは、投資対効果を描き、業務と組織を変革する人材を認定します。

資格が証明すること

スキルではなく、
「責任を持って変革を推進できる能力」を証明する。

AIエージェント・ストラテジスト資格は、4つの能力領域を評価します。 いずれも、大企業の現場でAI実装を推進するために不可欠な実務能力です。

01
業務分解力
現場の暗黙知を形式知に変換し、AIエージェントが実行可能な粒度まで業務を分解する能力。 BPRの視点から、業務プロセス全体を再設計できる。
02
ROI設計力
AI投資の対効果を数値で定義し、経営層への説明責任を果たす能力。 KPIの設定から効果測定の設計まで、意思決定を促す論拠を構築できる。
03
ワークフロー設計力
AIエージェントが機能する業務ワークフローを設計する能力。 人とAIの役割分担を明確にし、品質・例外処理・監視体制まで設計できる。
04
組織導入設計力
AI活用を組織に定着させるチェンジマネジメントの能力。 評価制度・職務定義の再設計からAIガバナンス体制の整備まで、 組織変革を構造的に推進できる。
カリキュラム

理論と実践を統合した、
6つの学習モジュール。

AIエージェントの本質理解から、業務設計・組織変革・ガバナンスまでを体系的に学びます。 すべてのモジュールは、大企業の現場で再現可能な実務知識として設計されています。

MODULE 01 AIエージェントの本質と活用類型 基礎理解
生成AIとAIエージェントの本質的な違いを理解します。チャットボット型・ワークフロー型・汎用型など活用類型の特徴と適用場面を整理し、自社の業務文脈に合った選択ができるようになります。
生成AI vs AIエージェント 活用類型の整理 企業導入の全体像
MODULE 02 コンテキストエンジニアリング基礎 設計基礎
AIエージェントが正しく機能するための「コンテキスト設計」を学びます。プロンプト設計の限界を超え、情報の構造化・権限設計・知識ベースの構築など、AIが業務で使える状態をつくる設計思想を習得します。
コンテキストの4層 情報構造化 知識ベース設計
MODULE 03 業務分解とBPR（業務プロセス再設計） 業務設計
現場の暗黙知を形式知に変換し、AIエージェントが実行可能な粒度まで業務を分解する手法を習得します。「汚いプロセスをそのまま自動化する」罠を避け、BPRの視点から業務を再設計します。
暗黙知の形式知化 業務フロー分解 BPRの実践
MODULE 04 ROI設計とKPI策定 投資設計
AI投資の効果を数値で定義し、経営層に説明責任を果たすためのフレームワークを学びます。定性効果の定量化、KPI設定、段階的な効果測定の設計など、意思決定を動かす論拠を構築できるようになります。
AI投資のROI定義 KPI設計手法 効果測定フレーム
MODULE 05 ワークフロー設計と品質評価 実装設計
AIエージェントが安定稼働するワークフローの設計手法を習得します。人とAIの役割分担、例外処理・エスカレーション設計、品質基準の策定など、実運用に耐えるAIワークフローを設計できるようになります。
ワークフロー設計パターン 品質基準の設定 例外処理設計
MODULE 06 組織設計とAIガバナンス 組織変革
AI活用を組織に定着させるチェンジマネジメントとガバナンス体制の構築を学びます。評価制度・職務定義の再設計、全社的なAI活用ポリシーの策定、野良AIの抑止など、持続可能なAI組織をつくる方法を習得します。

FAQ

どのような方が受験対象ですか？ +
DX推進担当・経営企画・人事/人材育成担当・部門マネージャー・業務改革担当など、AIエージェントを活用して業務や組織を変革する役割を担う方を主な対象としています。ITやプログラミングの専門知識は前提としておらず、業務経験をお持ちの方であれば受験いただけます。
試験の形式と難易度を教えてください。 +
試験はオンライン形式（自宅受験可）で実施します。多肢選択式と記述問題を組み合わせた構成で、試験時間は120分を予定しています。難易度は、公式テキストの内容を理解し、業務への適用を考えられるレベルを想定しています。詳細な出題範囲と合格基準は、2026年3月上旬に公開済みの受験要項をご確認ください。
AIエージェント・アーキテクト資格との違いは何ですか？ +
AIエージェント・ストラテジストは「戦略設計」担当者を認定する資格です。ROI設計・業務分解・組織変革の推進能力を評価します。一方、AIエージェント・アーキテクトは「技術実装」担当者を認定する資格で、ノーコードツールを活用したAIエージェントの構築・運用能力を評価します。両資格は役割を補完する関係にあり、企業内での分業体制を前提に設計されています。
公式テキストはいつから入手できますか？ +
ウェイトリストに登録いただいた方には、公式テキストを先行提供しています。2026年2月13日より登録受付中です。一般向けの公開時期については、公式サイト（aicx.jp）にてご案内します。
法人として複数名を受験させることは可能ですか？ +
はい、企業・団体単位での一括受験制度を予定しています。社内AI人材育成プログラムとしての活用も想定しており、団体割引なども検討しています。法人向けの詳細については、support@aicx.jp までお問い合わせください。
資格の有効期限と更新制度はありますか？ +
資格の有効期限・更新制度の詳細については、現在設計中です。AIの進化速度を踏まえた更新制度を検討しており、詳細が確定次第、公式サイトおよびウェイトリスト登録者へご案内します。
試験準備にはどの程度の学習時間が必要ですか？ +
業務でのAI活用経験をお持ちの方であれば、公式テキストを中心に20〜40時間程度の学習を目安としています。AIの基礎から学ぶ場合は、それ以上の時間を確保されることをお勧めします。AICX協会では学習をサポートするコンテンツも順次提供予定です。
